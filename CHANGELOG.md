# История изменений

## 1.0.6-beta — 21.11.2026

- Новый знак приложения: монограмма «VL» одной лентой на тёмно-изумрудной плашке.
  Обновлены иконка окна и exe, значок в трее, установщик, логотип и обложка README.
- Логотип приложения добавлен в шапку главного окна слева от карточки состояния.
- «Обход Zapret» и «Обход DPI» переведены на полную автоматизацию: убраны ручной
  выбор стратегий, кнопки «Подобрать», «Скачать/Установить» и «Проверить напрямую».
- Стратегии показываются информационным списком: с нумерацией, по 5 в столбик,
  автоматической сортировкой по приоритету лучшего результата.
- В обеих вкладках оставлена только галочка «Блокировать QUIC (UDP/443)».
- Для zapret блокировка QUIC реализована правилом Windows Firewall на время обхода;
  правило снимается при остановке/выходе и чистится после аварийного завершения.
- Кнопка «Виджет» перенесена в общий ряд вкладок рядом с «Общие»; клик открывает
  плавающий виджет, не переключая страницу.
- Автозапуск обходов перенесён в «Общие».
- Кнопки «Обновить списки», «Партия 500» и «Все узлы» выровнены в один ряд
  и оформлены в едином стиле.
- «Источники» упрощены и помещаются на экран: настройки автообновления скрыты
  (используются значения по умолчанию), убрана колонка «Моя». Остались выбор
  источников, добавление, обновление/поиск новых и удаление.
- Форма добавления источника стала понятнее: подписи «Название» и «Ссылка»,
  примеры адресов, многострочное поле для нескольких ссылок сразу.
  Кнопки приведены к единому стилю.
- Вкладка «Туннель» переименована в «Туннелирование» и упрощена: режим,
  что направлять через узел, список доменов и сохранение. Дополнительные
  настройки приложений и системного прокси скрыты — работают значения по умолчанию.
- Вкладка «Диагностика» убрана из интерфейса.
- «Настройки» сокращены до «Выбора узла» и «Фоновой проверки узлов»;
  остальные параметры работают со значениями по умолчанию и скрыты.
- «Туннелирование» переработано: сайты и приложения показываются плитками
  с иконками в две колонки; добавлены режимы «Туннелировать / не туннелировать»,
  выбор приложений из процессов и указание файла.
- «Источники»: список серверов расширен, форма ручного добавления компактнее.
- «Общие» перенесены в «Инструменты»; автозапуск обходов при старте убран.
- «Журнал» хранит последние 500 сообщений и отбрасывает старые.
- Виджет обновлён: 2×2 иконки YouTube/Discord/Универсальный/Telegram с числом
  рабочих узлов, ниже — «Обход запрет» и «Обход DPI». Вкладка «Виджет» оформлена
  как переключатель, в свёрнутом виде показываются флаг страны и уровень сигнала.
- Ядро sing-box проверяется и при необходимости обновляется автоматически при
  запуске; ручной блок «Ядро sing-box» скрыт.
- Добавлена проверка обновлений самого VieNLink через GitHub Releases: если версия
  новее, приложение предлагает скачать и установить обновление.

## 1.0.5-beta — 20.11.2026

- Версии схем `settings.json`, `nodes.json` и `mtproto.json`: старые файлы мигрируют,
  новые читаются с предупреждением — данные при обновлении не сбрасываются.
- `docs/VERSIONING.md`: политика версий, совместимость данных и порядок выпуска.
- Таблица поддерживаемых версий в `SECURITY.md`; CI запускается и на теги `v*`.
- В релизах лежат установщик, портативный ZIP и `SHA256SUMS.txt`.

## 1.0.4-beta — 20.11.2026

Первая публичная бета под именем **VieNLink** (ранее проект назывался DomVPN, ещё раньше — MyrrProxy).

### Добавлено

- Кнопка «Подключить / Отключиться» в шапке и быстрое меню узлов в трее.
- Скорость и суммарный трафик сессии в шапке (Clash API `/traffic`).
- Страна и IP выхода после подключения.
- Замер скорости узла (~1 МБ через узел), колонка «Скорость» и выбор узла для видео по скорости.
- Kill switch: при падении ядра системный прокси остаётся на закрытом порту.
- Автозапуск при входе в Windows (`HKCU\...\Run`, старт в трее).
- Проверка и обновление ядра sing-box; версия ядра видна в «Общих».
- Пресеты сайтов: YouTube, Telegram, Discord, Instagram, Facebook, X.
- Снятие loopback-изоляции для приложений Microsoft Store (`CheckNetIsolation`).

### Изменено

- Повторы узлов склеиваются мягче: на один `хост:порт` остаётся до 4 вариантов,
  чтобы не терять рабочие аккаунты с общих CDN.
- Проверка «сайт открылся» строже: успех только при коде < 400.
- Health-check реже (90 с, после сбоя 25–120 с) и адаптивная параллельность проверки.
- Источники при ошибке прокси повторяются напрямую.
- Сбой узла во время операции не теряется — переключение откладывается.
- `sources.dat` шифруется DPAPI; старые открытые копии удаляются.
- Конфиг ядра с UUID удаляется при отключении и выходе.
- Узлы с `tls.insecure` помечаются «⚠» и не выбираются первыми.
- Логи пишут стек исключения; журналы ротируются по 2 МБ.
- `MainWindow` разбит на partial-классы; добавлены golden-тесты и CI.
- Версии схем `settings.json`, `nodes.json` и `mtproto.json`: старые файлы
  мигрируют, новые читаются с предупреждением в журнале — данные не сбрасываются.

### Айдентика

- Новое имя и иконка: V + кольцо-связка, палитра графит/мятный.
- Логотип-вордмарк и обложка для GitHub — в `branding/`.
- Статус «бета» в шапке, заголовке окна, «Общих» и установщике.
