Политика конфиденциальности VieNLink
Privacy Policy

Дата вступления в силу / Effective date: 21.11.2026

Коротко: VieNLink не требует аккаунта, не содержит рекламы и аналитики и не передаёт ваши данные разработчику. Настройки, источники, кэш узлов и журналы хранятся только на устройстве.

Русский

1. Кто мы

VieNLink — клиент для работы с прокси-серверами и подписками. Проект открытый (GPL-3.0): github.com/VieNchikkk/VieNLink.

2. Какие данные обрабатываются на устройстве

  • Настройки: режим подключения, порты, правила маршрутизации, тема.
  • Источники и подписки: добавленные вами ссылки и полученные из них узлы. На Windows список источников шифруется средствами Windows (DPAPI), на Android — ключом в Android Keystore.
  • Кэш узлов и результаты проверок: адреса, задержки, отметки доступности.
  • Журналы приложения: события и ошибки для диагностики; хранятся локально и автоматически удаляются через 72 часа.
  • MTProto-прокси Telegram: найденные прокси и результаты их проверки.

Эти данные не покидают устройство, кроме случаев из раздела 3.

3. Сетевые соединения

  • загрузка списков и подписок по адресам, которые вы указали;
  • проверка узлов HTTP-запросами через сам узел (YouTube, Telegram, Discord, Cloudflare и список проверочных доменов);
  • чтение публичных RSS-зеркал Telegram-каналов, если включён сбор MTProto-прокси;
  • проверка обновлений и версии ядра на GitHub (в магазинной сборке обновления приходят из магазина);
  • передача вашего трафика через выбранный вами прокси-узел или VPN-туннель.

Владелец выбранного узла технически видит IP-адрес и объём трафика, а при незашифрованных соединениях — и их содержимое. Приложение не расшифровывает HTTPS. Бесплатные узлы из открытых списков никем не проверены — не используйте их для банковских и почтовых сервисов.

4. Чего приложение не делает

  • не создаёт аккаунты и не запрашивает персональные данные;
  • не содержит рекламы, трекеров и аналитики;
  • не отправляет журналы, историю посещений и настройки разработчику;
  • не продаёт и не передаёт данные третьим лицам.

5. Разрешения Android

  • VPN (VpnService) — основной режим: трафик идёт через узел.
  • Уведомления — состояние туннеля, ход проверки, готовность обновления.
  • Автозапуск — восстановление туннеля/обновления после перезагрузки, если включено.
  • Установка пакетов — только в GitHub-сборке для обновления APK с релизов. В сборке для Google Play/RuStore этого разрешения нет: обновления ставит магазин.

6. Дети

Приложение не предназначено для детей и не собирает данные о них.

7. Удаление данных

Все данные хранятся локально. Удалить их можно очисткой кэша/журналов в приложении, очисткой данных приложения в настройках Android или удалением приложения.

8. Изменения

Актуальная версия политики публикуется на этой странице; при существенных изменениях обновляется дата вступления в силу.

9. Контакты

Вопросы и запросы: GitHub Issues. Контактный e-mail разработчика указан в карточке приложения в магазине.

English

1. Who we are

VieNLink is a client for proxy servers and subscriptions. It is an open-source project (GPL-3.0): github.com/VieNchikkk/VieNLink.

2. Data processed on your device

Settings, user-provided sources/subscriptions and the nodes parsed from them, node cache and test results, local diagnostic logs, and discovered Telegram MTProto proxies. The sources list is encrypted with DPAPI on Windows and with an Android Keystore key on Android. This data stays on the device.

3. Network connections

The app connects to the network only to do its job: download the sources you added, test nodes with HTTP requests through each node (YouTube, Telegram, Discord, Cloudflare and a list of check domains), read public Telegram RSS mirrors when MTProto collection is enabled, check updates/core on GitHub (store builds receive updates from the store), and carry your traffic through the node or VPN tunnel you selected.

The operator of the node you choose can see your IP address and traffic volume, and for unencrypted connections also their content. The app does not decrypt HTTPS. Free public nodes are not audited — do not use them for banking or email.

4. What the app does not do

No accounts, no personal data requests, no ads, no trackers, no analytics, no upload of logs or settings to the developer, no sale or sharing of data with third parties.

5. Android permissions

VPN (VpnService) for the tunnel; notifications for tunnel/probe/update status; boot autostart if enabled; package installation only in the GitHub build for APK updates. Store builds do not request package installation.

6. Children

The app is not directed to children and does not collect data about them.

7. Deletion

All data is local. Delete it via in-app cache/log clearing, Android app-data clearing, or by uninstalling the app.

8. Changes

The current policy is published on this page; the effective date is updated when needed.

9. Contact

GitHub Issues — github.com/VieNchikkk/VieNLink/issues. The developer contact e-mail is listed in the store listing.
