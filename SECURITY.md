# Безопасность

## Поддерживаемые версии

Сейчас поддерживается только ветка **1.0.x (бета)**.

## Как сообщить об уязвимости

Не создавайте публичный issue с готовым эксплойтом. Используйте один из способов:

1. **GitHub → Security → Report a vulnerability** (private vulnerability reporting).
2. Приватный issue в этом репозитории с пометкой `security`.

Укажите версию, шаги воспроизведения и ожидаемое/фактическое поведение.
По возможности приложите фрагмент журнала из `%LOCALAPPDATA%\VieNLink\logs`.

## Что входит в область проверки

- Загрузка и запуск внешних компонентов: `sing-box.exe`, `wintun.dll`,
  `WinDivert.dll/.sys`, файлы zapret.
- Работа с реестром: системный прокси, автозапуск, восстановление после сбоя.
- Локальный Clash API и mixed-порт: доступность только с `127.0.0.1`, секрет API.
- Хранение секретов: `sources.dat` (DPAPI), конфиг ядра, журналы.
- Разбор недоверенных ссылок и подписок: инъекции в конфиг, DoS, утечки.
- Повышение прав: приложение работает `asInvoker`; UAC запрашивается только
  для TUN, zapret и WinDivert.

## Что не считается уязвимостью

- Владелец публичного узла видит ваш трафик: это описано в README.
- Блокировка узлов провайдером или недоступность сайтов.
- Срабатывание SmartScreen у неподписанной сборки.
- Локальный пользователь с правами вашей учётной записи: он и так может
  изменить файлы приложения и его данные.

## Рекомендации пользователю

- Не входите через бесплатные узлы в банки, почту и рабочие аккаунты.
- Для постоянной работы используйте свою подписку или свой сервер.
- Проверяйте, что релиз скачан из этого репозитория, а не со стороннего зеркала.
